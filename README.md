# 昨日热点

这是一个不依赖 ChatGPT 登录的 GitHub Pages 网站。页面从 `data/daily-news.json` 读取前一自然日的政策、机器人和商业机会榜单，支持三类标签筛选、站内摘要和原文跳转。榜单最多十条；当权威来源中符合条件的内容不足十条时，明确显示实际数量，不补造内容。

## 自动更新

GitHub Actions 在北京时间每天 00:10 运行 `scripts/collect-news.mjs`：从中国政府网、人力资源和社会保障部、工业和信息化部、国家发展改革委的公开栏目抓取标有目标日期的链接，按主题相关性和来源权威性排序，去重后保留最多十条。政策标签只分配给与高校毕业生、应届求职、招聘、实习见习、职业培训、创业、社保医保、住房租房、公积金、补贴税费、高校学生或青年人才有关的内容，并给予更高排序权重；不因标题出现泛化的“教育”二字而入选，与毕业生生活无直接关系的普通政策不会进入政策筛选结果。采集为空时，会重新按当前规则过滤最近一次成功榜单，再展示剩余内容，不伪造新内容。

## 文件职责

本项目没有 class：

- `index.html` 定义榜单、筛选和详情弹窗的结构。
- `app.js` 负责加载榜单、按标签筛选和展示详情。
- `styles.css` 负责桌面及移动端视觉样式。
- `scripts/collect-news.mjs` 的 `graduatePolicyTerms` 定义毕业求职和生活政策的纳入范围；`tagsFor` 只给命中该范围的条目分配“政策”标签；`parse` 过滤非标题链接并优先排序相关政策；`previousItems` 在采集失败时按同一规则过滤旧榜单；其余代码负责北京时间日期计算、抓取、去重和数据写入。
- `data/daily-news.json` 是页面读取的已生成榜单。
- `.github/workflows/daily-news.yml` 负责定时更新数据并部署 GitHub Pages。
- `tests/smoke.mjs` 验证页面结构、榜单数据依赖和已生成条目的基本完整性。

## 发布

推送至 `main` 后，GitHub Actions 自动部署。若这是仓库首次使用 Pages，请在仓库 Settings → Pages 中将 Source 设为 **GitHub Actions**。
